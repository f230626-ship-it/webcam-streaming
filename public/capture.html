Capture Client

This device captures webcam + microphone and streams to the viewer

Disconnected

What Happens When You Click Start:

1. Browser calls getUserMedia() to access camera + mic

2. Browser shows a permission prompt (you must allow it)

3. WebRTC peer connection is established via signaling server

4. Media streams directly to the viewer (peer-to-peer, not via server)

Security Indicators to Watch:

  • Browser: Green camera dot in tab, address bar icon
  • OS (macOS): Green/orange dot in top menu bar
  • Hardware: Green LED next to camera lens
